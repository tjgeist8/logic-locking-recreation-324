# Jack Helton and Tyler Geist Logic Locking Project

## Dependencies 

- Ubuntu 24.04.4 LTS
- Python 3.14.4
- conda 26.1.1
- yosys 0.64
- Matplotlib 3.10.9 (optional, AutoLock can use it)

### to clone environment use this command
```bash
conda env create -f environment.yml
conda activate logic_design
```
